localhost / static file server

http://127.0.0.1:8000/

Requests leave here and come back here. Nothing off this machine can reach it.

A static file server that does one thing and then shuts up about it. It serves your folders on the loopback address, on one port.

GitHub Releases

Install

brew install megamanics/tap/localhost

Or run the container. Each folder mounted under /srv becomes a path.

docker run -d --name localhost -p 127.0.0.1:8000:8000 \
  -v ~/prj/3d:/srv/3d:ro -v ~/notes/site:/srv/docs:ro megamanics/localhost

Or take a binary for macOS or Linux from the releases page.

Use

localhost [DIR] [NAME=DIR ...] [--port N] [--addr A] [--auth] [--quiet]

localhost 3d=~/prj/3d docs=~/notes/site
http://127.0.0.1:8000/3d/  →  ~/prj/3d
http://127.0.0.1:8000/docs/  →  ~/notes/site

With no arguments it serves the current directory at /. The root page lists what is mounted. A folder with no index.html gets a plain listing.
